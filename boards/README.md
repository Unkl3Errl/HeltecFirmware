# Heltec WiFi LoRa 32 V4 board files

This project contains one PlatformIO target:
`heltec-wifi-lora-32-v4`.

- `_boards_json/heltec-wifi-lora-32-v4.json` defines the ESP32-S3, 16 MB flash,
  2 MB PSRAM board.
- `heltec-wifi-lora-32-v4/` contains the PlatformIO environment, board
  interface, and passive WebUI validator.
- `heltec-wifi-lora-32-v4-variant/` contains the Arduino pin variant compiled
  for this board.

The hardware pin map and validation record are documented in
[`../HELTEC_V4_PORT.md`](../HELTEC_V4_PORT.md).
